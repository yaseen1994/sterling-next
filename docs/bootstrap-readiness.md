**Minimal safe scope if separately authorized:** a locally runnable Next.js/TypeScript/Tailwind foundation using the bootstrap prompt's confirmed router/package manager; reproducible package/lockfile and documented runtime; strict TypeScript, basic local layout and neutral root development page, configured lint/typecheck/build/dev/start scripts and focused smoke verification. Preserve docs/evidence and Git history. No production content, branding or reference-media import; no independent roadmap advancement. Codex may resolve routine compatible toolchain details within the supplied scope and document actual choices for ChatGPT review.

**Defer:** CMS/database/content schema, content migrations, permanent URL/redirect policies, mail/upload/careers integrations, analytics/consent implementation, real media/fonts/video/PDF reuse, hosting adapters, preview publication and cutover. No production DNS or WordPress changes. A future public preview needs its own approval and indexing protections before publication.

**Proposed acceptance checks:** clean reproducible install and documented Node/package versions; configured lint, typecheck and production build pass; dev server returns the neutral page; production start serves it and unknown route behavior is verified; no runtime/browser errors in the sampled local page; focused keyboard/mobile smoke check. These are foundation checks, not content/visual parity or email delivery. ChatGPT reviews the technical handoff; Yaseen remains product/browser acceptance reviewer.
